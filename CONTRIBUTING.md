# Contributing

VRCX-0-Nanashi is a personal fork maintained for one person's use. Pull requests
are not actively solicited, but small, focused fixes are welcome.

- Changes that are not fork-specific (bug fixes, general features) are usually
  better sent to upstream, [Map1en/VRCX-0](https://github.com/Map1en/VRCX-0),
  following its contributing rules.
- For anything large, open an
  [issue](https://github.com/NanashiTheNameless/VRCX-0-Nanashi/issues) first.
- UI text is English only; do not add translations.
- Issues and discussion must be in English. Other languages are not officially supported on
  this fork.
- Use plain ASCII punctuation (no em/en dashes, curly quotes, or emoji) in UI
  strings and docs.

## Using AI to write your PR

Fine, but you own what you submit: clean it up, read every line, and make sure it
actually solves the problem.

## Before submitting

- Make sure it builds and the checks pass. See [README](README.md) for setup.
- Keep the change minimal and on-topic.

Contributions are accepted under the project license (GPLv3). No CLA is required.
